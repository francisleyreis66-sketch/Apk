ANDROID BUILD STUDIO

ZIP TO APK BUILDER

Envie seu projeto ZIP ao GitHub e inicie uma compilação Android pelo GitHub Actions. Use diretamente no navegador do celular.

① Seu projeto

O arquivo será enviado ao repositório como input/projeto.zip. Limite recomendado: 50 MB.

② Conexão com GitHub

Crie um token com acesso ao repositório escolhido: Contents (Read and write) e Actions (Read and write). Não compartilhe o token. Ele fica somente nesta página e não é salvo.

③ Enviar e compilar

O construtor adiciona um workflow ao repositório, envia o ZIP e solicita a execução. O APK será publicado nos artefatos da execução.
Aguardando arquivo e configuração.

Como preparar o GitHub

1
Crie um repositório no GitHub. Pode ser privado ou público.
2
Crie um token em GitHub → Settings → Developer settings → Personal access tokens. Dê acesso somente ao repositório escolhido, com Contents e Actions em Read and write.
3
Preencha os campos acima e toque em Enviar ZIP. Não feche a página até a confirmação de envio.
Segurança: use um token de escopo limitado, não use computador ou celular compartilhado e revogue o token nas configurações do GitHub quando não precisar mais dele. O token não é transmitido a este desenvolvedor.
