🚀 APK pelo GitHub

Conecte sua conta, envie o projeto e o GitHub transforma em APK. Tudo pelo navegador do celular.

1. Conecte sua conta do GitHub

Crie um token de acesso (uma "senha" só para este app). O link abaixo já abre com as permissões certas marcadas: escolha validade de 7 dias, role até o fim e toque em Generate token. Depois copie o código e cole aqui.

🔑 Criar token no GitHub

🔒 O token só é enviado para api.github.com. Com "Lembrar" desmarcado, ele some ao fechar a página. Nunca o compartilhe. Você pode apagá-lo a qualquer momento em GitHub → Settings → Developer settings → Tokens.

2. Configure seu projeto

Se não existir, ele é criado automaticamente. Se já existir, os arquivos são atualizados.

Letras minúsculas separadas por pontos. Ele identifica o app no Android e não deve mudar depois.

3. Ícone do app (opcional)

4. Escolha os arquivos do projeto

Cole aqui o código HTML completo da sua página (do <!DOCTYPE html> até o </html>). Ele vira o index.html do app.

    6. Como instalar o APK
    
  
    O APK vem dentro de um ZIP. Extraia e abra o arquivo .apk. O Android pode pedir permissão para instalar apps de fontes desconhecidas.
    
  
    Se der erro
    
  
    O app mostra em qual passo a compilação falhou. Toque em Ver compilação e abra esse passo para ler a mensagem completa.
    
  
    O APK de depuração serve para testes. Para publicar na Play Store, você precisa de uma versão assinada, com a chave guardada em Settings → Secrets do repositório.
    
 
    
 
    Funciona localmente no navegador. A compilação acontece nos servidores do GitHub Actions e precisa de internet.
