Teclado e controle

Teclado: setas movem · X = A · Z = B · A = L · S = R · Enter = Start · Shift = Select · Espaço = avançar · R = voltar no tempo (APK) · F2 salva e F4 carrega o estado 1 · Esc abre o menu.
Controle USB/Bluetooth: direcional, botões da direita (A/B), L1/R1, Start/Select, R2 avança.
